```matlab
nValues = [2, 4, 6];

    for j = 1:numel(nValues)

        [b, a] = butter(n, Wn, 'low');

        plot(w/pi, 20*log10(max(abs(h),1e-8)));

end
```

3. `interp1` 路径：构造新时间轴 `tNew`，用线性插值得到 `yInterp`。
4. 为了清晰对比差异，在原有整段图（不太容易观察）基础上新增两类细节图：

### 关键代码片段
```matlab
% resample
[p, q] = rat(targetFs(k) / fs, 1e-12);
yRes{k} = resample(x, p, q);

% interp1
t = (0:numel(x)-1)' / fs;
tNew = (0:1/targetFs(k):t(end))';
yInterp{k} = interp1(t, x, tNew, 'linear');
```
