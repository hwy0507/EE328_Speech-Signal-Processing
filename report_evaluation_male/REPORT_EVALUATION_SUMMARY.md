## Key Claims for the Report

1. **Anonymity improves strongly:** ASV EER rises from `0.000` for the original source to `0.583` for `Raw metric male, Metric+phone male, PPG-tone male`.
2. **Speaker identity similarity drops:** source-speaker cosine score falls from `0.716` for original speech to `0.060` for `PPG-tone male`, a `91.5%` reduction.
3. **ASR is disrupted:** WER rises from `0.000` for the non-anonymized baseline to `0.655` for `Metric+phone male`. For the naturalness trade-off, compare `Metric+phone male, PPG-tone male`.
4. **Best visual effect index:** `PPG-tone male` has the highest local effect index, combining ASV EER, source-similarity reduction, and WER. This is an explanatory index for the report, not an official VoicePrivacy metric.
5. **Best identity-privacy ranking:** `PPG-tone male` ranks first when EER ties are broken by source-speaker similarity reduction.

## EER Granularity Note

The local test set currently has `2` target trials and `12` non-target trials, so ASV EER changes in coarse steps. Methods with the same EER are therefore not necessarily identical. In the best-EER group, the fine-grained order by source-speaker similarity reduction is: PPG-tone male (91.5% drop), Metric+phone male (91.4% drop), Raw metric male (89.4% drop).
